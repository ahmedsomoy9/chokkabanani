# Chokka Banani Presence

Create a premium, modern, fully responsive restaurant website for Chokka Banani, a restaurant located in Banani, Dhaka, Bangladesh.

BRAND & VISUAL DIRECTION

The website should feel warm, elegant, cozy, artistic, and premium.

The client specifically requested a wooden + white textured aesthetic.

Use:

Light natural wood textures

Warm off-white / ivory backgrounds

Subtle brown and muted gold accents inspired by the Chokka logo

Dark charcoal/brown text

Soft shadows

Subtle rounded corners

Elegant but readable typography

Plenty of whitespace

High-quality food photography

Subtle animations that feel premium, not excessive

Do NOT make the website look like a generic fast-food template. It should feel like a stylish independent restaurant with a warm atmosphere.

Use the provided Chokka logo, food photographs, and menu images as the primary visual assets. Do not replace the client's food photographs with random stock photos if the provided photos are available.

WEBSITE STRUCTURE

1. NAVIGATION

Create a clean sticky navigation bar containing:

Chokka logo

Home

About

Menu

Events & Workspace

Location

Contact

Add a prominent “View Menu” button.

On mobile, use a clean hamburger menu.

2. HERO SECTION

Create a visually striking hero section using one of the provided food photographs.

Display:

CHOKKA BANANI

A short elegant supporting line such as:

Good food, warm moments, and a space to gather.

Add two buttons:

Explore Menu
Contact Us

Do not make claims about awards, popularity, or customer numbers.

The hero should immediately communicate that this is a premium restaurant in Banani.

3. ABOUT SECTION

Create a clean introduction section for Chokka Banani.

Use a warm, natural tone and keep the copy concise.

Do NOT invent a founding story, chef biography, awards, years of experience, or other facts that were not provided by the client.

Focus on the restaurant experience, food, atmosphere, and the fact that the space can also accommodate events and work-related use.

4. FEATURED FOOD SECTION

Create a beautiful visual food section using the provided food photographs.

Feature several dishes with large images and subtle hover animations.

Do not invent dish names if they aren't confirmed.

The photos should be displayed with high-quality cropping and responsive behavior.

5. MENU SECTION

Create a premium digital menu using the menu information provided by the client.

Organize the menu into clear categories:

Baked Pasta

Italian Pasta

Pizza

Rice Creation

Bites

Tea

Wellness Infusion

Cool Fun

Use the exact dish names, descriptions, and prices from the provided menu images.

Do NOT change, invent, or guess menu items or prices.

Display prices clearly in BDT (৳).

For pizza, clearly distinguish between the 8 inch and 12 inch prices where applicable.

Make the menu easy to browse on mobile.

Add subtle category navigation/tabs if appropriate.

6. EVENTS & WORKSPACE SECTION

Create a dedicated section highlighting that:

Chokka Banani offers space for Events and Workspaces.

Use a stylish layout with an appropriate provided image if available.

Add a call-to-action:

Inquire About the Space

This button should lead to the contact/WhatsApp section.

Do not invent event packages, capacity, rental prices, or facilities unless the client provides them.

7. DELIVERY SECTION

Create a simple attractive section:

Delivery Available in Banani

Explain that customers can contact Chokka for delivery information.

Add a prominent WhatsApp/contact button.

Do not claim delivery is available outside Banani unless the client confirms it.

8. LOCATION & CONTACT

Create a visually clean contact section containing the confirmed information:

Chokka Banani

Address:
House 93, Road 6, Block C, Banani, Dhaka

Opening Hours:
12:00 PM – 11:00 PM

Phone / WhatsApp:
+880 1866-033673

Add buttons for:

WhatsApp

Instagram

Facebook

Google Maps / Directions

Instagram:
https://www.instagram.com/chokka_banani

Facebook:
https://www.facebook.com/share/19JRa6dXLx/

For Google Maps, create a directions link using the restaurant's address rather than inventing coordinates.

9. FOOTER

Create a premium minimal footer containing:

Chokka logo

Restaurant name

Address

Opening hours

Phone number

Instagram

Facebook

Add a small copyright line.

UX REQUIREMENTS

The website must be:

Fully responsive

Mobile-first

Fast loading

Easy to navigate

Accessible

Professional enough to be shown to a real restaurant owner

Optimized for mobile screens

Smoothly animated but not overloaded with animations

Buttons should have clear hover states.

Images should be optimized and use lazy loading where appropriate.

The navigation should remain easy to access on mobile.

IMPORTANT CONTENT RULES

Use the client's provided images and menu as the source of truth.

Never invent:

Reviews

Ratings

Awards

Customer numbers

Restaurant history

Chef information

Opening dates

Prices not present in the supplied menu

Event capacity

Rental packages

Delivery areas beyond Banani

If information is missing, use a simple contact/inquiry call-to-action instead.

FINAL DESIGN GOAL

The final result should look like a real premium restaurant website, not an AI-generated template.

Think:
natural wood + ivory paper + warm restaurant atmosphere + beautiful food photography + elegant typography + modern UI.

Keep the design sophisticated and uncluttered.

The website should make the restaurant owner immediately think:

“This looks like our brand.”
